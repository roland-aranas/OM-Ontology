# O&M Instruction Ontology

This repository contains an ontology developed from interviews with
Orientation & Mobility (O&M) specialists and blind and low-vision learners.

The ontology represents concepts related to mobility skills, instructional
strategies, feedback, learner characteristics, environments, hazards,
practice conditions, sensory cues, instructional goals, and instructional
tools.

## Files

- `ontology.ttl` — ontology serialized in RDF/Turtle
- `queries/` — SPARQL competency queries used in evaluation
- `figures/` — ontology visualization

## Status

Version 0.1.0 — research prototype / candidate ontology.

The ontology was constructed using a human-in-the-loop LLM-assisted pipeline.
The schema and extracted relationships should not be interpreted as a
comprehensive or independently validated representation of O&M practice.
